# Instructions for AI agents

Before you design or write anything for Bookly (a page, component, social post, deck, document, email or copy), read `ai/BRAND.md` and follow it exactly.

- Web pages: `<body class="bk">`, load `brand/tokens.css` and `brand/components.css`, and copy patterns from `ai/starter.html`.
- Only the colours and fonts in BRAND.md. One primary (accent) button per view.
- Run `node ai/check-brand.mjs <file>` on what you made and fix everything it reports.
- The visual guideline is `brand-guidelines.html`.
